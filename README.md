# StreamerApp — Трансляция экрана по локальной сети

Настольное приложение на **C# / WPF (.NET 10)** с встроенным **ASP.NET Core** веб-сервером, **SignalR** и **WebRTC** для трансляции экрана и системного звука в локальной сети с минимальной задержкой.

## Возможности

- **Захват экрана**: выбор монитора, переключение движка захвата (`DXGI (GPU)` через `Vortice.Direct3D11` / `GDI (CPU)`), отображение курсора мыши.
- **Параметры потока**: выбор разрешения (`Original`, `1920x1080`, `1280x720`), частоты кадров (`15` / `30` / `60` FPS), битрейта (`500–8000` Кбит/с) и захвата системного звука (`NAudio`).
- **Доступ по комнате**: автоматическая генерация 6-значного кода комнаты (`XXX-XXX`), список подключённых зрителей с пингом и индикатором «поднята рука».
- **Веб-интерфейс зрителя (`wwwroot`)**: подключение из любого браузера в локальной сети по IP и порту (`http://<IP>:5000`), просмотр видеопотока, встроенный чат с ведущим.

## Сборка, тесты и запуск

```powershell
dotnet build StreamerApp\StreamerApp.csproj
dotnet test StreamerApp.Tests\StreamerApp.Tests.csproj
dotnet run --project StreamerApp\StreamerApp.csproj
```
